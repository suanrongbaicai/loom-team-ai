## 怎么跑

从仓库根目录运行，最小演示和常规离线检查只需要 Python 标准库：

```sh
python examples/local_demo.py
python tools/run_tests.py --quick
python tools/run_tests.py --json output/tests.json
```

测试会创建合成文件、临时数据库、假工作进程和本地 HTTP 接口。运行器限制当前 Python 进程对外的 socket 连接，只允许本地接口；这不是操作系统级的网络沙箱，不能替任意新增子进程承诺断网。演示另有检查，任何 socket 连接都会报错。

## 25 项为什么跳过

- 18 项需要符号链接权限，这台 Windows 环境无法创建测试所需链接。
- 4 项属于较新 SQLite 下的连接优化，本环境的 SQLite 版本保持优化关闭。
- 3 项需要显式选择并提供真实 Codex CLI 的本机离线宿主检查，本轮没有启用。

跳过不能算通过。部署时要在目标环境补验相应条件。最小示例只用标准库，代码没有依赖这些 Windows 权限；Linux 已有上述独立审阅结果；macOS 完整测试尚未验证。

## 那 1 项预期失败是什么

`tests.test_test_marking` 中的测试消息标记原型尚未完成，对应检查标为 `expectedFailure`。我把它列在未完成项里，不当作功能已经通过。
