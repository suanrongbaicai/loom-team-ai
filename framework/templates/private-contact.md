# 主动私聊办理方法

适用：用户明确指定成员与事项；或正在办理已授权工作，需要相关团队成员补充信息、协调或作业务决定。先用 member_find 核对稳定成员、已知称呼与职责。同名不能合并；群任务限定已核验 group，排除写入本次任务 exclude。

给每人准备必要且自然的正文，purpose 说明事项，basis 只列本人实际读过且收件人有权阅读的资料。contact_private 的 mode 分别使用 specified 或 work。宿主复用现有私聊，缺少时通过正式消息接口取得单聊，不创建群。每个批次固定 id，后续用 contact_status 核回执。

queued 未发送；sent 只证明平台接受；delivery_failed 是明确拒绝；unknown 保留待核且不得换 id 重发。部分成功逐人反馈。状态中的回复数仅指联络后实际收到的消息，不证明已读或已回答。收件人回复以本人身份进入自己的私聊，利用已有称呼、职责和当前回答逐步续办；不复制发起人完整历史，不重复问卷，也不补发历史群接引。

工具目录：member_find 查当前机器人/租户内已核验团队候选；contact_private 按任务保存并排队逐人消息；contact_status 查本人的当前机器人批次、实际回执和消息数。工具不接受自填机器人、租户、open_id、网址或路径。
